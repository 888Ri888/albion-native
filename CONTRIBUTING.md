# Contributing

Albion Native is my project. Help is welcome on an open issue. Unsolicited rewrites of the vision are not.

## Rules

- Open a pull request against an existing issue, or open an issue first.
- Do not commit game files, dump folders, screenshots of ripped assets you do not own, or absolute paths from your machine.
- Use `FABLE2_DUMP` in docs and tests. The variable points at a local GOTY tree. The tree stays local.
- A behavior change needs evidence: a clip, a trace, or a script reference. Label guesses as guesses.
- Match the voice of this repo. Do not add a second product name.

## Good first work

- Foliage model sub-format.
- Texture conversion, with a synthetic fixture in git and the real file kept local.
- One GLB in a Bevy scene, behind the dump variable.
- Animation curve-mode values that stay in range.

## Pull requests

Say which issue you are closing, what you ran, and what you did not test. A maintainer merges. A fork is not the project.
