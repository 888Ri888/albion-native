# Maintainers

jxnplays merges to `main`.

Work that came from a private notes repo is rewritten before it lands here. Private notes do not get copied in. Commit messages name the change, not the tool that drafted it.

Every pull request that moves a chunk also edits the board at the top of `README.md`. The rule is `docs/BOARD.md`. A merge without that edit is a mistake.

A pull request from outside is reviewed against the issue, the legal file, and this page. Helpful work is merged. Drive-by rebrands are closed.
