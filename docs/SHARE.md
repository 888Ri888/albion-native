# If you were sent here

This is a production book for a clean-room Rust and Bevy engine. Fable 2 GOTY is the first world. The game code is in a private working tree. This repo does not build a game by itself.

The Sunday ask is one converted mesh, one original texture, and Bloodstone ground in the Bevy window. It is not a 1:1.

Help that lands: a pull request against one open card, with a test or a shot, and no game file. Help that does not: a second engine, a recomp of the executable, or a rewrite of the board.

Read `README.md`, then `docs/ISSUES.md`. Fork. Do not push to `jxnplays`.
