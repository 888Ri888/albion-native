# Repos

Albion Native is the master. The game repos are standalone ports. A model in a game repo does not become the engine. A model in the master does not start a second Fable 2.

| Repo | What it is | Now |
|---|---|---|
| `jxnplays/albion-native` | Master engine. Worlds, board, contract, merge. | This book. |
| `jxnplays/fable2rustybev` | Standalone Fable 2 GOTY port. Current focus. Keep it. | Only tree with code. Formats, converter, window. |
| `jxnplays/fable1rustybev` | Standalone Fable, The Lost Chapters, and Anniversary. | Not opened. Nothing to keep. |
| `jxnplays/fable3rustybev` | Standalone Fable 3 port. | Not opened. Starts when Fable 2 is 1:1. |
| `jxnplays/fablelegendsrustybev` | Standalone Legends port. | Not opened. Last. |

`albion-legends` and `fable2-bnk-extractor` are empty. Do not mine them. Do not delete `fable2rustybev`.

Each standalone must run on its own. Albion Native then loads that world as a pack. Fable 2 is the only port with a builder until its 1:1 bar is met.
