# Repos

Albion Native is the master. The game repos are standalone ports. A model in a game repo does not become the engine. A model in the master does not start a second Fable 2.

| Repo | What it is | Now |
|---|---|---|
| `jxnplays/albion-native` | Master engine. Worlds, board, contract, merge. | This book. |
| `jxnplays/fable2rustybev` | Standalone Fable 2 GOTY port. Current focus. | Working tree. |
| `jxnplays/fable1rustybev` | Standalone Fable, The Lost Chapters, and Anniversary. | Not opened. |
| `jxnplays/fable3rustybev` | Standalone Fable 3 port. | Not opened. Starts when Fable 2 is 1:1. |
| `jxnplays/fablelegendsrustybev` | Standalone Legends port. | Not opened. Last. Legal source only. |

Each standalone must run on its own. Albion Native then loads that world as a pack. Shipping only inside the master is a failure. Shipping a fork that cannot join the master is a failure.

Fable 2 is the only port with a builder until its 1:1 bar is met. The other names exist so nobody invents a different layout later.
