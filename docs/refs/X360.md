# Xbox 360

The pattern is static recomp, then a native runtime. Albion does not take that path. The catalogs are still the map of what has already been done.

| Repo | Use |
|---|---|
| `abduznik/awesome-x360-recomps` | Index. Start here. |
| `hedge-dev/XenonRecomp` | PowerPC to C++. Sonic Unleashed is the flagship. |
| `rexglue/rexglue-sdk` | Current 360 recomp SDK. |
| `sp00nznet/360tools` | Harness and playbook around ReXGlue. |
| Skate 3 recomp, listed in the awesome index | Closest "full native 360 port" shape. Not Fable. Do not port its runtime in. |
| Sonic Unleashed Recompiled, `hedge-dev` | Same. Settings, ultrawide, and mod-loader patterns only. |
