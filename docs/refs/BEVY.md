# Bevy

| Repo | Use |
|---|---|
| `Mudcrab-Team/mudcrab` | Same shape as this project: Bevy engine, owned install, no assets in git. Skyrim, not Fable. |
| `jxnplays/rusty-scrolls` | Our Skyrim-first port on that base. Separate project. |
| `Neopallium/bevy_water` | Wave material. See `docs/graphics/`. |
| `bevy-aqua` on crates.io | Caustics and FFT. Version-locked. |
| `bevy_feronia` | Grass and wind. |
| `bevyengine/bevy` `examples/3d/atmosphere.rs` | TAA, bloom, fog, SSR. |
| `rust-gamedev/rust-game-ports` | Small ports. Pattern for a crate split, not a content source. |

Graphics crates are pinned in `docs/graphics/STACK.md`. This file is the index.
