# Brain

The brain is not a model. It is the production memory: what was decided, what was proven, and what is still open. Models read it. They do not get to rewrite it because a session ran long.

## What belongs in the brain

- A decision, with the date and the reason.
- A format note backed by a fixture or a cited script.
- A status line that matches a merged pull request.
- An open question, marked as open.

## What does not

- A machine path.
- A legal name.
- A dump listing.
- A claim that a system is done because a prototype compiled somewhere else.

The public brain is this repository. Private working notes stay in the private ops repo. A note moves here only after it has been rewritten for strangers.

## Hive

The hive is whoever is currently assigned. It is not a fixed cast, and it is not a single model with a long prompt.

A production pass uses more than one model on purpose. One model builds. Another reviews. A third may hold a department the builder is not in. The studio head chooses the seats before the pass starts. If a seat is unassigned, that department does not move.

Models do not share a hidden channel that overrides the repository. What the hive agreed is what was written into an issue, a pull request, or a brain page.
