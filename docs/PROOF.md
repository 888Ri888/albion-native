# Proof

A percent on the home board needs one of these in the pull request. A sentence in a finding is not proof.

| Claim | Proof |
|---|---|
| It parses | A test on a synthetic fixture, or a count from `FABLE2_DUMP` with no file committed. |
| It shows | A shot of the Bevy window. |
| It plays | The shot plus the input that caused it. |
| It is 1:1 | The card id and the script, clip, or trace. |
| An issue closed | The issue id from `docs/ISSUES.md` in the pull request title. |

I-01 through I-04 close only with the Sunday shot. Closing them in prose is rejected.

Review checks the issue table, the board row, and the legal file. Three edits, or the pull request is incomplete.
