# Fable 2 GOTY

This is the feature map for a legitimate 1:1 of the GOTY edition. A row is not done because a prototype exists in a side folder. A row is done when it runs from `FABLE2_DUMP` and the pull request names the evidence.

Base game first. Knothole Island and See the Future are GOTY content, scheduled after the base spine, not after a menu screenshot.

## Regions

| Region | Required for 1:1 | State |
|---|---|---|
| Bowerstone (Market, Old Town, Fairfax Gardens) | Yes | Not rendered |
| Oakfield and Rookridge | Yes | Not rendered |
| Bloodstone and the sinkhole road | Yes | Data parses. Not drawn. |
| Westcliff | Yes | Not started |
| Wraithmarsh | Yes | Not started |
| Bower Lake, bandit coast, the road network | Yes | Not started |
| Crucible, the Spire approach | Yes | Not started |
| Knothole Island | GOTY pack | Not scheduled until the base road can be walked |
| See the Future | GOTY pack | Not scheduled until the base road can be walked |

Bloodstone is the first street because its scenario has already been parsed. It is not the only town.

## Evidence rule

A quest, a damage number, or a line of dialogue needs a script call, a trace, or a clip. If the evidence is missing, the row stays open. The engine does not invent Albion to fill a percentage.

## Definition of the port

Fable 2 GOTY is 1:1 when a player who owns the edition can start a new game, walk the regions, finish the base quests and both packs, and save, without the original executable in the loop. Emulation remains the oracle until that sentence is true.
