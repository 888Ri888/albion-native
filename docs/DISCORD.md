# Discord

Private server. The repo is the tracker. Discord is the feed. Models do not chat here.

Name: Albion Native. Invite only. Studio head is the owner.

## Roles

| Role | Who |
|---|---|
| Studio head | jxnplays. Only merge, only invite. |
| Builder | A person or a session you named. |
| Reviewer | A different person. Cannot approve their own row. |
| Guest | Read `#board` and `#shot`. No write. |

## Channels

| Channel | What lands |
|---|---|
| `#start` | The paste from the home page. Pinned. |
| `#board` | GitHub commits and pull requests, via the Discord GitHub integration. |
| `#shot` | The Sunday shot, and any later shot. One image, one issue id. |
| `#blocked` | Dump not found, or a row that cannot move. |
| `#ports` | Fable 2 catch-up. Later games only after you open them. |
| `#engine` | Second world. Empty until the street exists. |
| `#tools` | NPC names, GLB drop, window seat. |
| `#remote` | RustDesk up or down. No password. |

## Feed

Server Settings, Integrations, GitHub. Authorize as jxnplays. Point commits and pull requests at `#board`. Add `albion-native` and `fable2rustybev`. Both are private, so the login has to be yours.

A model does not post. A proven push is the post.
