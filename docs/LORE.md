# Lore archive

The archive is an index, not a strategy guide. A card says what a thing is and what it does. It does not paste dialogue, item stats tables, or walkthrough steps.

Source of names: the public Fable Wiki category indexes. A card that adds a fact beyond the name says where it came from. A card with no script link stays `indexed`.

## Card

```text
ID:
Game:
Kind:
Name:
Does:
Region:
Status: indexed | evidenced | running
Source:
```

`Does` is one sentence. Status moves to `evidenced` only with a script, clip, or trace. Status moves to `running` only with a merged system chunk.
