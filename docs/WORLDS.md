# Worlds

| World | Role | Scheduled |
|---|---|---|
| Fable 2 GOTY | First world. Defines the runtime. | Now |
| Knothole Island, See the Future | Content of the first world. | After the base regions run |
| Fable 3 | Second world pack on the same runtime. | After the Fable 2 spine is playable |
| Fable: The Lost Chapters | Later world. Different original engine. | Not scheduled |
| Fable Legends | Later world. Restore and rebuild. | Not scheduled |

A world pack may add maps, creatures, and scripts. It may not add a second engine.
