# Settings

One menu. Defaults are the 1:1 look. Remaster toggles start off.

| Setting | Default | Chunk |
|---|---|---|
| Resolution scale | 1x | After the window is stable. |
| Sharpen | Off | CAS-style, after 2x exists. |
| Shadow quality | Low | With the first street lights. |
| Ambient occlusion | Off | After the street. |
| Bloom | Off | Bevy bloom. |
| TAA | Off | Bevy temporal AA. |
| Volumetric fog | Off | Bevy fog volume. |
| Screen-space reflections | Off | After water exists. |
| Water waves | Off | [WATER.md](WATER.md) |
| Caustics | Off | Requires waves. |
| Grass density | Original | [FOLIAGE.md](FOLIAGE.md) |
| Tree distance | Original | Same. |
| NPC density | Original | [CROWD.md](CROWD.md) |
| Crowd extra | 0 | Remaster only. |

A setting that does nothing is not added. Grounded mantle, parachutes, and other modern-CoD options are out.
