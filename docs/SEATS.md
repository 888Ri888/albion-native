# Seats

Suggestions, not appointments. jxnplays assigns the seat. A suggested model that is down, expensive, or wrong for the slice gets replaced. Do not spend money on a larger model until a free seat has failed the same brief twice.

Context matters more than brand. Format work and world data want a long context. Review wants a different model than the one that wrote the change.

## Suggested assignment

| Department | Suggested seat | Why | Spend |
|---|---|---|---|
| Studio head | jxnplays | Vision and merge. Not a model. | None |
| Production | A long-context coder already in the hive | Issues, status, slice order. | Free seat first |
| Tools | Long-context coder | Parsers, fixtures, converters. Large files. | Free |
| Engine | Long-context coder, different session from Tools | Bevy runtime only. | Free |
| World | Long-context coder | Heightfields and placement tables are wide. | Free |
| Animation | Long-context coder | Clip tables and curve mode. | Free |
| Gameplay | Long-context coder | Player, dog, combat. Needs the runtime already booting. | Free |
| Narrative | Long-context coder plus a review seat | Lua evidence. Easy to invent. Review rejects invention. | Free |
| Audio | Tools seat, later | Banks are a decoder problem before they are a mix problem. | Free |
| Presentation | Engine seat, later | HUD and lighting after a street exists. | Free |
| Review | A second model, never the builder | Evidence, scope, legal. | Free. Pay only if review keeps missing dump files or false claims. |

## Current free seats that fit

Long-context coding seats already used on this production are enough for Tools, Engine, World, Animation, and Gameplay. Use two of them, not one. The builder does not review its own pull request.

A paid frontier model is justified only for Review after a free reviewer has passed a pull request that contained a game file, a faked status line, or a quest with no script evidence.

## What the person reading this must do

Before a pass, write the assignment in the issue:

```text
Department: World
Builder: <model you chose>
Review: <a different model>
Brief: Draw the Bloodstone heightfield. No props.
```

If those three lines are missing, the pass does not start.
