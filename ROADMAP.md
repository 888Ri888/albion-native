Exit: a pull request with a screenshot of that street and a test that does not require the dump to be in git.

Walk, run, idle, from the decoded clips. Curve-mode animation fixed or explicitly rejected with a note.

One Lua-backed quest from extracted scripts, started and completed in the runtime. Evidence linked in the pull request. No dump files in the pull request.

## M4. The Fable 2 GOTY spine

Regions, the road, the dog, jobs, weapons, spells, morality. Each is an issue. None of them are implied by M1.

## M5. Fable 3 as a world pack

Same runtime. New map and script set. Starts only after M4 is playable.
