# Legal

You need to own Fable 2, preferably the GOTY or Platinum edition, title ID `4D5307F1`.

This repository never contains game assets. Releases never contain game assets. The converter and the game read `FABLE2_DUMP` on the machine running them.

Do not open a pull request that adds an ISO, an executable from the game, an extracted archive, or a guide scan. Those will be closed and the files removed.

Xenia and existing recompilation projects are third-party oracles. Albion Native does not ship their runtimes as the game.

Research quotes stay short and attributed.
